## How to work (owner orders, 26 Nov 2026 late)
### The loop, per row
1. Read the row and ONLY the doc section it points to (grep the heading). Never read `V8_PLAN.md`, `V9_PLAN.md` or `NOW.md` whole.
2. Read the code it touches (grep first), find the real cause in the code, then build the WHOLE row as well as you can, the first time:
   - every point in its doc;
   - phone first;
   - a Config switch, on by default;
   - the server decides; remotes through `Net` with a validator and a rate limit.
3. Put the changed scripts into Studio through the MCP; check each by length or checksum.
4. **ONE quick Play,** only to see that the output shows no error from your change, then stop it. For a row about how something LOOKS, take one capture in that same Play.

6. Save the place. Commit and push `release`. Update the row here (State, LEFT).
7. `git pull --rebase` (the cloud session pushes new rows and generated files such as `OwnerMapPlan.luau`), re-read THE ORDER, and go straight on to the next row. Never end the run after one row or one phase.
