**How to test (owner)**
1. Creator Dashboard → the experience → Places/Thumbnails: upload 3-5 thumbnails.
2. Under "Thumbnail Personalization / Experiment", turn on the A/B test (Roblox splits impressions and reports CTR).
3. Upload both icons as a second icon test, if the dashboard offers it for your account.
4. Let it run 7 days. Keep the winner.
